NOVALINK GLOBAL V4 WEBSITE SETUP

The package now includes the official NovaLink logo as logo.png.

1. Upload ALL files to the ROOT of the GitHub repository. Keep index.html, styles.css and logo.png in the same folder.
2. REAL ENQUIRIES: create a form endpoint and replace YOUR_FORM_ID in contact.html. GitHub Pages itself does not process server-side forms.
3. GOOGLE ANALYTICS: create a GA4 web data stream and paste the Google tag into every page before </head>.
4. GOOGLE SEARCH CONSOLE: add the Domain property novalinkglobal.lk and submit https://www.novalinkglobal.lk/sitemap.xml.
5. PROFESSIONAL EMAIL: choose an email provider and add its MX/SPF/DKIM records at the domain DNS manager. Do not remove the GitHub Pages records.
6. E-COMMERCE: the current version provides the catalogue and enquiry foundation. A real checkout/payment system requires a backend/payment provider and should be added after product, shipping, tax and payment requirements are finalized.
